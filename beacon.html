What problem does this solve?

Verifying analytics implementations manually is tedious and error-prone. QA teams spend hours clicking through websites, inspecting the console for dataLayer events, and documenting issues — often missing edge cases or intermittent tracking failures.

Description

Beacon is a program that gives users the ability to record steps on a website and have them automatically replayed. At each step, the program reads the dataLayer and shows which measurement points (tags, events, variables) are found.

This makes it an invaluable tool for QA testing of analytics implementations, allowing analysts and developers to verify that tracking is firing correctly at every user interaction without manual inspection.

Example

Input: Record a user journey: Homepage → Product page → Add to cart → Checkout.

Output: Detailed report showing all dataLayer events fired at each step, with pass/fail indicators for expected tracking points.

How to start

  1. Install the Beacon Chrome extension
  2. Navigate to the website you want to test
  3. Click "Start Recording" and perform your user journey
  4. Click "Stop" and review the captured dataLayer events
  5. Save or export the report for documentation

What access is needed?

  • Google Chrome browser (latest version)
  • Chrome DevTools Protocol access
  • Node.js 18+ (for the recording server)
  • Access to the target website in a test environment
  • Basic understanding of Google Tag Manager / dataLayer
