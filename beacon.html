Description

Beacon is a program that gives users the ability to record steps on a website and have them automatically replayed. At each step, the program reads the dataLayer and shows which measurement points (tags, events, variables) are found.

This makes it an invaluable tool for QA testing of analytics implementations, allowing analysts and developers to verify that tracking is firing correctly at every user interaction without manual inspection.

Who is this for?

Beacon is designed for analytics specialists, QA engineers, and front-end developers who need to validate dataLayer implementations on websites. It is especially useful during tag management audits and when verifying tracking setups for new features or page templates.

Dependencies & Requirements

  • Google Chrome browser (latest version)
  • Chrome DevTools Protocol access
  • Node.js 18+ (for the recording server)
  • Access to the target website in a test environment
  • Basic understanding of Google Tag Manager / dataLayer
