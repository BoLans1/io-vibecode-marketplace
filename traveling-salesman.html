Description

The Traveling Salesman Solver is a workflow combined with back-end system integrations and Google Maps to answer classic traveling salesman problems. It determines who can best visit which location and when, optimizing routes for teams working across multiple sites.

The tool takes a list of locations, available personnel, time windows, and constraints, then computes the most efficient assignment and route plan using advanced optimization algorithms.

Who is this for?

This tool is ideal for project managers, field service teams, and operations coordinators who need to efficiently plan on-site visits across multiple locations. It is particularly useful for teams that need to balance travel time, availability, and client preferences.

Dependencies & Requirements

  • Python 3.10+ runtime environment
  • Google Maps Platform API key (Directions API enabled)
  • Access to the iO internal scheduling backend
  • Bonzai workflow engine (for automated scheduling)
  • Docker (optional, for containerised deployment)
