Description

Ads App is an internal advertising management platform built for a marketing agency. It is a SaaS web application that allows an operator (the agency) to manage and monitor the advertising campaigns of multiple clients from a single console.

The platform integrates with major ad networks to pull real-time campaign data, enabling operators to track performance, adjust budgets, and optimize targeting — all from one unified dashboard.

Who is this for?

This tool is designed for marketing teams and advertising operations specialists within iO who manage campaigns across multiple client accounts. It streamlines the workflow by centralizing campaign data and controls.

Dependencies & Requirements

  • Node.js 18+ and npm
  • PostgreSQL 14+ database
  • Google Ads API credentials
  • Meta Business API access token
  • Docker (recommended for local development)
